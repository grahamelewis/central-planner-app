The loop: speak → release → turn runs (tool tail on screen, optional spoken updates) → Claude speaks the result → mic reopens. That cycle, with the phone in your pocket, is the "extremely useful virtually" scenario — checking on an overnight estimation without touching a keyboard.
·
Requirement carried over from the plan: the mic only exists on secure origins, so remote phones must use the https://…ts.net Tailscale serve URL (the phone app's install path already recommends exactly this). On plain-HTTP LAN addresses the orb renders disabled with a one-line explanation and a link to REMOTE.md.
·
Deliberately absent: no wake word, no always-on listening. Hold-to-talk on the phone (with release-to-send) keeps mic time explicit and battery/privacy sane; the lock gesture from mockup 02 exists here too, as a long-press on the orb.
