The Send button becomes the countdown. Amber (the dashboard's existing "needs you" color), spinner ring, live count. Clicking it sends immediately; the count reaching zero sends; anything that looks like editing cancels. No modal, no second confirm — one calm beat in the exact spot your eye already watches.

The hint line flips from green to amber with the countdown's two escape hatches. In hands-free mode (mockup 05 / settings) this delay drops to zero and the message sends on release — the pause is a default, not a gate.

Why not send instantly by default? Browser recognizers mishear technical vocabulary ("Aiyagari", package names, file paths) more than prose. A 3-second glance costs almost nothing; an errant turn costs tokens and, under auto oversight, possibly actions.
