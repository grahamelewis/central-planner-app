Usage stays visible at the bottom real percentages for every connected provider

Codex exposes its quota windows, used percentage, and reset timestamps through app-server. The collapsed bar keeps both short-window percentages glanceable; the open panel shows every returned window. Click the bottom meter to close and reopen it.

1
Both providers stay glanceable. Claude and Codex keep separate percentages because their windows and reset schedules are unrelated. The active task’s provider is brighter.
2
The percentage means “used,” consistently. Tracks fill toward the limit, turn yellow at 70%, and red at 90%, matching the dashboard’s existing Claude convention.
3
Reset labels are derived, not assumed. Codex returns windowDurationMins and resetsAt; the UI converts those into labels and live countdowns.
4
Authentication matters. ChatGPT-backed Codex logins expose plan windows. API-key-only usage should show API spend/rate-limit data instead of pretending it has a ChatGPT-plan percentage.
