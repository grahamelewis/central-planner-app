The combined chooser models grouped by connected provider

The catalog opens upward from the existing session bar. Try selecting a different Claude model, changing reasoning effort, or choosing a Codex model. A provider change on an existing conversation triggers the boundary dialog.

1
Grouped, not mixed. Model names can be similar and catalogs will evolve. Provider grouping is the stable organizing principle.
2
Model change within Claude is next-turn only. It can reuse the same Claude thread, matching the dashboard’s present behavior.
3
Provider change creates a new provider thread. The transcript remains in the task, with a handoff summary supplied to the new thread; there is no claim that Codex resumed Claude.
