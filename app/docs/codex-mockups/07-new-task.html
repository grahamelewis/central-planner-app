Choose the agent on a new task explicit in storage, lightweight in the form

The new-task form starts from the account default and saves both provider and model. Try switching between Claude and Codex; each service exposes only its own relevant model controls.

1
Provider is a first-class task field. It must not be inferred from the model name; explicit storage makes migration and provider-specific behavior safer.
2
Only connected services are candidates. In the single-service versions of this form, the provider card can collapse to one quiet selected row.
3
Defaults reduce friction, not control. New tasks inherit the Settings default, while every task can override it before launch or from its session bar.
