Design review · no production changes

Claude + Codex in the planner

This suite proposes a provider-neutral session experience that remains quiet for people with one service, scales cleanly to both, and never pretends a thread can move invisibly between providers. Every model control in the numbered pages is clickable. Use the Dark / Bright switch on any page and resize the browser—the workbench re-composes at tablet and narrow-pane widths instead of preserving a clipped desktop canvas.

One compact control: provider + model Explicit boundary: provider changes start a thread Clean single-service mode: no disabled catalog No silent fallback: reconnect or choose Always-glanceable usage: real percentages at the bottom
