④ One-line ticker

the minimal fix: ONE patching line per agent, plus one permanent line when each finishes
Idea. Exactly what the karaoke/answer line already does for speech: each agent owns ONE line that patches in place (verb, tok, clock), so the stream never accumulates status spam; when an agent finishes, its line freezes into the permanent verdict row. Stragglers: automatic — finished lines freeze with "✓ … 7m ago", the grinder's line keeps ticking. Scale: 24 lines is still 24 lines; the workflow state compresses to one line per PHASE plus the busiest agent. Cheapest to build (the console already patches segments in place); least structure.
