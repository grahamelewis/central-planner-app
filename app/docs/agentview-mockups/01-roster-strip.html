① Roster strip

a sticky one-glance summary pinned above the stream; agent chatter leaves the stream
Idea. One pinned strip: headline count (3 agents · 2 running) + one chip per agent showing its CURRENT action, patched in place — the stream below keeps only spawn lines and the orchestrator's own text, so the chronology stops being spammed by status repeats. Stragglers: done chips dim to their one-line result and stop moving; the grinder keeps its live verb and elapsed. Scale: past ~8 agents the chips collapse to counts per status and the strip stays one line tall (workflow state shows this). Click a chip → that agent's lines filter into view (not mocked).
