⑤ Swimlanes

the console splits into parallel columns during a fan-out — each agent streams in its own lane
Idea. True parallel reading: each agent's last few tool lines stream in a NARROW COLUMN, so simultaneity is visible spatially instead of interleaved. Stragglers: finished lanes collapse to a header-only stub; the live lane widens. Scale is the honest problem: columns stop working past ~4 agents — the workflow state shows the degradation (lanes give way to a count + "busiest lane" view, which is really variant ② wearing lanes' clothes). Prettiest for 2–4 agents; not the generalizer.
