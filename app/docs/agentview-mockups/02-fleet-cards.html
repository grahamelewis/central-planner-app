② Fleet cards

a card per agent, grid-wrapped — the workflow board look, inside the console
Idea. Agent chatter becomes a live CARD GRID at the fan-out point in the stream: name, mission, current tool verb, tok/elapsed. Cards patch in place — no repeated lines. Stragglers: done cards shrink to verdict + "3m ago" and dim; the grinder's card stays bright with a running clock — instantly visible who's holding the turn. Scale: the same grid wraps to 24 (workflow state groups cards under phase headers with progress bars) — this is the layout that degrades best to "large team". Cost: tall — the grid pushes the prose stream down when many agents run.
